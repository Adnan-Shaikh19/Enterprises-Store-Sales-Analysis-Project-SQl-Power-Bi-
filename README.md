# Enterprises-Store-Sales-Analysis-Project-SQl-Power-Bi-
# End-to-End Analytics Dashboard (SQL & Power BI)

## 📌 Project Overview
This project delivers an end-to-end business intelligence solution using **SQL** for backend data extraction/transformation and **Power BI** for frontend modeling, dynamic reporting, and interactive visualizations. Built the dashboard provides actionable insight through key performance indicators (KPIs) and trend analyses.

## 🔑 Key Features
* **SQL Data Pipeline**: Developed custom SQL scripts and views to cleanse, aggregate, and structure raw transactional data for optimal dashboard performance.
* **Relational Data Modeling**: Built an efficient data model connecting dimension and fact tables, backed by DAX measures for real-time calculations.
* **Multi-Page Interactive Layout**: Structured intuitive analytical views using Power BI's modular page configuration (`.json`).
* **Modern UI/UX**: Styled with the **Fluent2** theme (`Fluent2-CY26SU08.json`) for a clean, cohesive enterprise user experience.
* **Data Security & Governance**: Enforced Role-Level Security (RLS) via security bindings to ensure controlled data exposure based on user roles.

## 🛠️ Technology Stack
* **Database & Querying**: SQL (Queries, Views, CTEs, Aggregations)
* **Visualization & Analytics**: Power BI Desktop / Service, DAX, Power Query (M)
* **Metadata & Project Format**: Power BI Project (`.pbip`)
